### 踩坑经验已固化到测试脚本中：

1. **登录入口**：首页无文字"登录"按钮，通过点击 `img[alt=avatar]` → popover → `.to-login-btn-tooltip .button` 进入登录
2. **弹窗检测**：`dismissPopups()` 在每个步骤前调用，双层检测机制（Playwright 定位器 + JS 兜底）
3. **两步式登录表单**：先输入手机号 → 点击"注册/登录" → 密码框才出现
4. **按钮文本空格**：登录按钮文本为"登 录"（中间有空格）
5. **Canvas 遮挡**：画布编辑器中所有底部按钮需 `click({ force: true })`
6. **模板选择流程**：展开输入区 → 切换"模板"tab → 点击"选择创意模板" → 搜索 → 选中
7. **生成按钮文本**：按钮文本为算力数值（如"35"），用正则 `/^\d+$/` 匹配
