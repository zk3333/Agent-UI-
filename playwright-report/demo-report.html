🔄 委派 ui-healer-agent 子代理

定位器失效/动作失败时，主代理收集失败凭据，委派专业自愈子代理推导替代定位器（零幻觉、有界重试）。

1
收集自愈凭据
优先读 error-context.md（ARIA 快照）+ test-failed-1.png + trace，不重新 MCP 登录走流程
2
判断失败类型
定位器失效/动作失败 → 委派；业务逻辑 bug → 停止自愈，出 bug 报告
3
委派 ui-healer-agent
传入 failingStep / attemptedAction / errorText / pageContext，子代理按定位优先级推导修复
4
消费结构化结果
返回 status/finalLocator/evidence；healed 则更新 spec 并 --grep 只重跑失败步骤
5
最多 3 轮，避免死循环
3 次仍失败 → 换思路重试或升级人工排查，不再盲目循环

踩坑经验精选 · 36 条沉淀库

skill 内置 36 条踩坑经验库，每轮执行中发现的新难点持续补充，以下为本次全链路测试覆盖的关键经验。

#1
登录入口非文字按钮
页面无「登录」文字按钮，登录入口为头像 img[alt=avatar] → popover → 点击 .to-login-btn-tooltip .button
定位器
#3
账号密码登录两步式表单
填手机号 → 点击「注册/登录」→ 密码框才出现，非一次性表单
时序
#8
Canvas 画布遮挡底部按钮
画布编辑器全屏 canvas 覆盖底部按钮，必须用 click({ force: true }) 绕过遮挡；JS el.click() 对 Vue/React 组件无效
遮挡
#14
弹窗任意时机出现
dismissPopups 双层检测：Playwright 定位器 + JS 遍历，只关不含 input 的推广弹窗，避免误关登录对话框
弹窗
#24
生成完成判断不依赖进度文案
顶部进度提示生成完成后仍常驻，以「创作记录出现结果图」为完成标志，最长轮询 600s
断言
#26
自愈提速：读失败产物
优先读 error-context.md + test-failed-1.png，不重新 MCP 登录走流程；候选定位器链减少自愈轮次
性能
#29
删除作品入口 4 轮自愈定位
详情页无删除入口；正常作品卡 footer 的 .artwork-item__actions-more → 菜单含「删除」→ 二次确认
自愈
#34
预清理黄金范式
safe-delete shim 拦截 rmSync / Remove-Item；改用 PowerShell Move-Item 移入 $env:TEMP，工作区零垃圾
环境
#35
全链路超时必须 > 600s
AI 生成服务端固定耗时不可压缩，test.setTimeout 设 30 分钟，避免超时打断伪装成点击失败
超时
